# Часть 2 - Видео-презентация недвижимости

## Структура проекта

```
part2/
├── index.html       # Основной HTML файл с видео-презентацией
├── part_2.png      # Изображение макета для референса
└── video.mp4       # Видеофайл презентации
```

## Описание

Вторая часть проекта представляет собой страницу с видео-презентацией элитной недвижимости. Основной акцент сделан на полноэкранном видео-контенте, который демонстрирует преимущества и особенности объекта.

### Особенности

- Полноэкранное видео в качестве фона
- Адаптивный дизайн для всех устройств
- Оптимизированная загрузка видео
- Интерактивные элементы управления видео
- Возможность просмотра в различных разрешениях

### Технические детали

- Видео формат: MP4
- Размер видео: 6.6MB
- Поддержка современных браузеров
- Оптимизация для мобильных устройств


### Рекомендации по оптимизации

- Рекомендуется использовать CDN для раздачи видео-контента
- При необходимости можно добавить несколько форматов видео (WebM, MP4) для лучшей совместимости
- Для мобильных устройств рекомендуется предусмотреть версию видео меньшего размера
